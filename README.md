# Simple Billing & C# OOP Practice

A small C# learning repository with multiple Visual Studio projects. The visible billing exercise accepts item details, price, and quantity, calculates a subtotal, applies a 15% discount, and displays the resulting amount. The repository also includes a separate OOP practice project.

## Concepts demonstrated

- Console input and output
- Classes and private fields
- Calculating item totals and discount values
- Formatting and displaying a simple bill
- Basic C# project structure

## Technology

- C#
- .NET / Visual Studio projects (see the included `.sln` and `.csproj` files)

## Run locally

1. Open the relevant solution in Visual Studio.
2. Choose the desired console project as the startup project.
3. Build and run the project.
4. Follow the console prompts for item ID, name, price, and quantity.

## Notes

This is a learning exercise, not a complete billing/POS system. Add numeric validation, currency-safe decimal arithmetic, error handling, and tests before using the calculations for real transactions.
